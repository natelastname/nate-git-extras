## Global invariants

- Keep documentation and tests up to date.
- Never mark a task complete while tests or docs are out of sync.

## Required completion checklist

1. Identify changed files.
3. Update or create documentation if behavior changed.
4. Add or update tests.
5. Run fast validation.
6. Summarize remaining risks explicitly.

## Testing conventions
- New behavior requires tests.
- Bug fixes require a regression test.
- Refactors should preserve behavior and keep tests green.
